# Cache

A personal expense tracker built with React Native + Expo.

Snap a receipt, log an amount and category, and review your monthly spending — all stored locally on device.

## Stack

- [Expo](https://expo.dev) (managed workflow)
- React Native 0.85 + React 19
- TypeScript
- React Navigation v7
- Zustand
- AsyncStorage
- expo-image-picker

## Running locally

```bash
pnpm install
pnpm start
```

Then press `i` for iOS Simulator or scan the QR code with Expo Go.
